# Archived documentation

These files describe the earlier standalone Admin Studio (a React web app and
iOS build behind an Express proxy server with OAuth sign-in, deployed to AWS,
Railway and Vercel). That architecture was replaced by the ISC UI plugin,
which has no server, no sign-in of its own and no native build. The files are
kept as a record and are not maintained:

- [APP_STORE_LISTING.md](APP_STORE_LISTING.md): App Store copy for the removed iOS app.
- [AWS_DEPLOYMENT_PLAN.md](AWS_DEPLOYMENT_PLAN.md): as-built record and plan for the server deployment.
- [REBUILD_PROMPTS.md](REBUILD_PROMPTS.md): a prompt sequence for rebuilding the server-based app. Its Phase 0 ISC constraints still hold.
- [WEB_APP_DESCRIPTION.md](WEB_APP_DESCRIPTION.md): marketing copy for the web app.

Current documentation starts at [../../README.md](../../README.md).
